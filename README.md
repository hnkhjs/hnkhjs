### Selected work — B2B ordering & dashboard

卸側・店舗側の受発注と、その上に乗るダッシュボードを継続的に改善しています。

- 商品マスタの検索モード、CSV 一括登録、文字コードエラーをその場で分かるようにする
- 発注履歴の状態表示・税抜金額など、現場が見て判断できる情報設計
- 納品カレンダー、定期注文の日付（曜日）、帳票・レポート表の視認性
- 複雑なテーブルを「読める・触れる・壊れない」状態に保つ

Ongoing work on supplier/store ordering flows and the dashboards on top of them: master-data search, CSV import UX, order-history states, delivery calendars, and report tables that people can actually read.
